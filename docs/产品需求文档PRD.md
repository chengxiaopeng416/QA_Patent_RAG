# 产品需求文档（PRD）

**项目：企业知识问答V2.1 | 作者：张伟 | 日期：2026-05-20**

## 1. 目标

- 将检索准确率提升至93%以上
- 支持多模态文档（图片、表格）
- 将平均响应时间降至2秒以内
- 增加个性化推荐功能

## 2. 用户

- 全部800+员工
- 日活跃用户：350+，日查询量：5000+
- 关键用户画像：知识工作者、管理者、新员工

## 3. 功能

- **F1**：多模态文档解析
- **F2**：个性化推荐
- **F3**：基于反馈的持续改进
- **F4**：管理后台
- **F5**：意图感知路由

## 4. 非功能性需求

- **性能**：p95 < 2秒，QPS > 50
- **可用性**：99.9%
- **安全**：JWT + RBAC + SQL注入防护
- **可扩展性**：1000并发，10000+文档
