# 华信科技有限公司 2024年员工手册 V5.0

**生效日期：2024-01-01 | 公开文档**

## 1. 公司概况

- 成立于2015年，总部位于北京中关村
- 800+员工，60%以上为研发人员
- 核心业务：企业AI解决方案、智能知识管理、数据分析

## 2. 工作时间

- 周一至周五 9:00-18:00，午休 12:00-13:30
- 经经理批准可实行弹性工时
- 加班按劳动法规定补偿

## 3. 休假制度

| 假别 | 说明 |
|------|------|
| **年假** | 1-5年工龄5天，5-10年8天，10-15年12天，15年以上15天 |
| **病假** | 发放80%工资，3天以上需提供证明 |
| **婚假** | 3天 |
| **产假** | 158天 |
| **丧假** | 3天 |

## 4. 薪酬福利

- 基本工资 + 绩效奖金 + 年终奖
- 社会保险 + 住房公积金 + 补充医疗保险
- 年度健康体检
- 学习津贴3000元/年

## 5. 行为准则

- 保密义务
- 禁止兼职
- 禁止骚扰行为
- 违规行为向人力资源部报告
- 着装要求：商务休闲，客户会面时着正装
