# 华信科技有限公司 - 员工手册

## 一、公司简介

华信科技有限公司成立于2015年，是一家专注于人工智能与大数据技术研发的高新技术企业。公司总部位于北京中关村科技园，在上海、深圳、成都设有分支机构。现有员工800余人，其中研发人员占比超过60%。

## 二、企业文化

- **使命**：用技术驱动企业数字化转型
- **愿景**：成为国内领先的企业智能化解决方案提供商
- **价值观**：创新、协作、诚信、卓越

## 三、员工行为规范

1. 工作时间：周一至周五 9:00-18:00，午休12:00-13:30
2. 着装要求：工作日需穿着商务休闲装，重要会议需穿着正装
3. 保密义务：员工不得泄露公司商业秘密和技术秘密
4. 通讯规范：工作邮件须在24小时内回复，企业微信消息须在2小时内回复

## 四、请假制度

| 假期类型 | 年假天数 | 薪资待遇 |
|---------|---------|---------|
| 年假 | 5-15天 | 全薪 |
| 病假 | 按工龄 | 80%薪资 |
| 事假 | 按需申请 | 无薪 |
| 婚假 | 3天 | 全薪 |
| 产假 | 158天 | 全薪 |

## 五、晋升通道

公司实行双通道晋升体系：
- **管理通道**：员工 → 主管 → 经理 → 总监 → 副总裁
- **技术通道**：初级工程师 → 中级工程师 → 高级工程师 → 技术专家 → 首席科学家
